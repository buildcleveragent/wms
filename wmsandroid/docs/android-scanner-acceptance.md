# Android 手机摄像头扫码验收

在与生产一致的自定义基座和至少两台普通 Android 手机上执行。验收时同时观察设备日志与后端请求日志。

1. 打开商品搜索页，扫描同一条码一次：只振动一次、只发起一次商品查询。
2. 首次拒绝相机权限：应显示用途说明；再次拒绝或永久拒绝后，应可跳转系统设置。
3. 从 POS 切换到拣货、复核或移库页再扫描：只有当前按钮触发一次摄像头，不得改变隐藏页面状态。
4. 验证闪光灯、远距离一维码、二维码和 DataMatrix，每次返回后只振动一次、只产生一次业务请求。
5. 断开仓库 Wi-Fi 后恢复：普通作业可重试；POS 结果未知时必须使用同一快照和幂等键重试。

全部项目通过后再进入内部灰度；灰度期间按设备和操作员检查单次扫码对应的业务请求数量，并逐笔核对销售、库存、退货和作废结果。
