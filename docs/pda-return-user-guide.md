# PDA 退货出库使用手册

- 文档版本：V2.2
- 业务基线：2026-10-17 当前工作区，包含未提交修改；不表示已部署。
- 适用人员：具有单一仓库范围及退货出库权限的仓库操作员。
- 相关文档：[岗位手册索引](manuals/README.md) · [部署、接口与历史验证记录](pda-returns.md)。

本手册按当前页面及服务端校验编写，本次更新未执行实际扣库、冲销或设备测试。

## 1. 选择正确流程

| 现场需求 | 应使用的流程 |
|---|---|
| 仓库把货退给货主或可追溯的原供应商 | 本手册“退货出库” |
| 顾客退回已购买商品，并记录退款 | [POS 使用手册](pos_user_manual.md)中的销售退货 |
| 原货主转给另一货主，再销售给客户 | 仓库操作员手册中的代办转货 |

退货出库只处理库存，不处理退款、售价、供应商结算或货权转移。确认即扣库存，不需要再走销售审核和拣货。

## 2. 班前准备

1. 登录本人账号，核对所属仓库，刷新首页权限资料。
2. 打开“退货出库”。入口缺失时请管理员检查角色、`outbound.process_pda_return` 权限及前后端版本，不能借用他人账号。
3. 核实退货原因、接收方及实物数量；按库位、批次、效期、容器、序列号区分库存。

## 3. 建单与填写数量

1. 在“新建 / 详情”选择库存货主，搜索或扫码查商品；同条码多个货主时明确选择库存所属货主。
2. 选择具体库存行，核对库位、批次、效期、容器和序列号。不同库存维度分别录入。
3. 按下表填写基本单位数量，最多四位小数；一单最多 200 条明细。

| 数量栏 | 来源与限制 | 整单冲销后的去向 |
|---|---|---|
| 正常退货 | 从可用库存扣减 | 恢复原库存维度的正常库存 |
| 已登记破损 | 从已登记破损库存扣减，不能超过破损量 | 恢复为破损库存 |
| 现场发现破损 | 从可用库存扣减；与正常退货合计不能超可用量 | 恢复为破损库存 |

例如某库存可用 10 件、原有破损 2 件，可填正常退货 6、现场发现破损 4、原有破损 2；不能填正常 8 加现场破损 4。已分配、锁定库存不能直接退货。

4. 选择“退给货主”或“退给供应商”。只有所选库存有共同且可靠的原供应商来源时才能退供应商；未知来源退货主，不同供应商分别建单。
5. 填写退货原因，最多 200 字。可先“保存草稿”，在“退货记录”重新打开；只能修改、删除本人草稿。清空明细并重新选择其他货主前，先确认不再使用原内容。

## 4. 确认并扣库存

1. 复点实物，核对货主、接收方和三类数量。
2. 点击“确认退货”，在确认框再次核对后提交，等待结果。
3. 成功后记录退货单号，状态为“已完成”；在原单和库存查询中确认扣减。
4. 库存不足、供应商来源不符、维度失效或成本层异常会拒绝整单；按具体提示处理，不能拆单掩盖差异或手改库存。

“保存草稿”不扣库存，“已完成”已经扣库。不要再对该退货执行普通出库。

## 5. 结果不明时恢复原请求

遇到网络中断、服务异常或响应不完整，页面会保留待确认操作并显示“继续确认结果”。保留原设备本地数据，恢复网络后使用原账号、原仓库点击该按钮。待确认期间不修改原内容、不重建替代单，也不清应用或浏览器数据。

提示权限不足时请管理员恢复或核对权限，再处理原请求；提示版本或库存变化时刷新原记录并核查。仍无法确认时记录单号、时间、经办人和完整提示交接，不能把“没有成功提示”当成没有扣库。

## 6. 错误退货的整单冲销

1. 原经办人打开本人“已完成”退货单，核实货物仍在仓库或已实际退回。
2. 填写必填冲销原因，点击“整单冲销”并确认。
3. 成功后原单变为“已冲销”，保留原记录并恢复原库存维度。现场发现破损仍计破损，不能重新作为可用货销售。
4. 冲销结果不明时同样“继续确认结果”；原库存维度或 FIFO 成本层已变化而被拒绝时交管理员排查，不能手工补库存冒充冲销。

冲销针对整单，不支持只冲销其中一行；其他操作员不能代为冲销本人单据。

## 7. 查询、统计与导出

在“退货记录”查询原单、状态及明细；在“退货统计”选择日期，按货主、供应商、接收方类型、商品或操作员筛选，点击“查询”或“导出 Excel”。仓库统计页也提供退货统计入口。

- 默认当天，统计和导出最长 366 天；超过 50000 个事件行须缩小范围。
- 确认计入确认当日，冲销计入冲销当日；跨日冲销保留原日实绩。
- 净退货 = 退货 − 冲销；不同基本单位分别汇总，不能直接相加。
- 导出包含汇总、明细及正常、原有破损、现场破损的区分；下载成功后核对文件和筛选范围。

## 8. 日结检查

- [ ] 草稿、已完成及已冲销单据分清，原单号可追踪。
- [ ] 实物、接收方和库存变化一致，没有重复出库。
- [ ] 待确认请求已恢复，未解决事项按原单交接。
- [ ] 冲销已核对实物及破损状态，没有手工补库存。
- [ ] 统计按操作日期、基本单位和实际筛选范围核对。
