# WMS 角色—入口—权限—数据范围—动作核对表

本表以 2026-08-04 当前工作区中的 `UserRoleScope`、规范角色组模板、Profile 能力字段、客户端菜单和服务端动作校验为准。

## 规范角色矩阵

| 角色 | 正式权限组 | 入口 | 显式数据范围 | 默认核心权限 | 主要动作 | 明确禁止或非默认能力 |
|---|---|---|---|---|---|---|
| 仓库操作员 | `WMS::仓库操作员` | `wmspda` | 单一仓库 | `access_warehouse_operations`、`receive_without_order`、`view_wmstask`、`claim_task_as_wh_operator`、`process_warehouse_assisted_outbound`、仓库运营报表 | 有/无订单收货、上架、代办出库、拣货、复核、库存与报表查询 | 不做货主/仓库管理审核；商品导入和 POS 需额外权限 |
| 仓库管理员 | `WMS::仓库管理员` | Web 控制台 / Admin | 单一仓库 | 仓库管理、入出库查看/修改/确认、任务管理/确认、库存明细/汇总/流水/快照、运营报表与导出 | 入出库确认、保留任务发布、驳回、任务审核/过账、库存与异常监督 | 不代替货主审核；计费、商品导入、POS 和权限管理非默认能力 |
| 仓库老板 | `WMS::仓库老板` | `wmsbossbilling` | 可配置多个仓库 | 老板看板、仓库运营、仓库财务、运营导出 | 查看经营总览、库存库容、收入计费和预警 | 只读，不开单、不审核、不调整库存、不发布或过账任务 |
| 货主管理员 | `WMS::货主管理员` | `wmsownersale` | 单一货主 | 货主管理、货主财务、货主运营报表与导出、入出库查看/修改/货主审核 | 审核并冻结库存、带原因退回、取消、库存/履约/账单核对 | 不做仓库确认和实物作业，不查看其他货主 |
| 货主业务员 | `WMS::货主业务员` | `wmsownersale` | 单一货主 | 货主业务、货主运营报表、入出库查看/新增/修改/提交 | 选择授权仓库、开单、草稿、提交/撤回、退回后编辑重提、一件代发导入 | 不做货主审核、仓库确认或任务过账，不查看其他货主 |
| 系统管理员 | 无 `UserRoleScope` 业务角色；使用超级管理员或审批后的后台权限 | Web 控制台 / Admin | 超级管理员全局；普通后台账号仍按显式范围 | 用户、角色范围、辅助权限、基础资料、配置和审计 | 开通/停用账号、维护角色范围、基础资料与受控配置、审计排查 | 不代替业务岗位；普通后台权限不能绕过角色范围 |

## 关键业务动作与责任分工

| 动作 | 发起角色 | 后续责任角色 | 服务端关键控制 |
|---|---|---|---|
| 标准出库开单与提交 | 货主业务员 | 货主管理员 | 原创建人、货主范围、授权仓库、价格、库存和幂等校验 |
| 货主审核通过 | 货主管理员 | 仓库管理员 | 仅已提交订单；重新校验价格；冻结库存并生成 `RESERVED` 任务 |
| 货主退回修改 | 货主管理员 | 原创建业务员 | 退回原因必填且不超过 200 字；订单回到可编辑草稿 |
| 仓库确认发布 | 仓库管理员 | 仓库操作员 | 必须先货主审核；只允许完整分配且唯一的保留任务发布 |
| 撤回、驳回或取消 | 业务员、货主或仓库管理角色按状态执行 | 仓库管理员核对 | 任务已开始或有执行数量时禁止直接释放；成功后核对冻结库存 |
| 有订单收货与上架 | 仓库操作员 | 仓库管理员监督 | 只能领取并执行当前仓库任务；库位必须属于任务仓库；请求幂等 |
| 无订单收货 / Excel 入库 | 仓库操作员 | 仓库管理员核对 | 明确货主和仓库；模板范围、追溯字段和整批一致性校验 |
| 拣货与标准复核 | 仓库操作员 | 不同操作员复核，仓库管理员监督 | 标准出库拣货人与复核人分离；完成后统一过账 |
| 库存调整 | 取得相应高风险权限的管理人员 | 仓库管理员/系统管理员审计 | 必须有真实原因和依据；不得直接改库存明细或汇总 |
| 账单核对 | 货主管理员、取得财务权限的仓库角色、仓库老板 | 财务/系统管理员排查 | 按角色范围读取；差异追溯业务来源，不直接改总额 |

## 命名和兼容规则

- 企业岗位“仓库主管”需要管理作业时，系统角色使用 `WMS::仓库管理员`。
- 旧用户组名称“仓库主管”是 `warehouse_boss` 的兼容别名，会被识别为仓库老板。
- 权限决定能力，显式角色范围决定能够触达的数据；两者缺一时按拒绝访问处理。
- 同一普通账号只能有一种活动业务角色；仓库老板可在同一角色下配置多个仓库范围。
