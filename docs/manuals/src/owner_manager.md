## 角色职责与权限

货主管理员负责本货主订单的商业审核、退回、取消，以及库存、履约报表和财务数据核对。规范角色组为 `WMS::货主管理员`，必须配置一个活动货主范围。

默认能力包括货主订单管理、货主运营报表和货主财务查看；不能查看其他货主数据，不能代替仓库管理员确认发布，也不能执行仓库现场拣货、复核或过账。

## 每日审核顺序

1. 登录货主业务端，在“功能 → 订单审批”查看待审核数量。
2. 优先处理交付时限临近、一件代发和库存紧张订单。
3. 审核前打开详情，不能只根据列表摘要批量判断。
4. 审核结束后查看已通过、已退回和已取消标签，确认处理结果。
5. 定期核对实时库存、入出库履约、销售报表和计费总览。

## 订单审核通过

1. 在“订单审批”打开待审核订单。
2. 核对货主、履约仓库、客户、平台单号、商品、包装换算、数量、成交价、总金额和收件信息。
3. 确认订单为已提交、未关闭且状态允许审核；草稿、已撤回、已退回或已取消订单不能审核。
4. 复查当前商品价格规则。系统会使用审核时的最新最低价和折扣限制再次校验，不能依赖业务员提交时的旧价格。
5. 确认业务真实、价格合规、地址完整且不存在明显重复后点击“审核通过”。
6. 审核通过会冻结/分配库存，并创建或刷新 `RESERVED` 拣货任务；这时任务尚未发布，仍需仓库管理员确认。
7. 返回列表确认状态为货主已通过，必要时通知仓库处理待确认订单。

库存允许欠货的后台审核路径仍必须留下完整订单和分配结果；不得把“审核成功”理解为库存已经扣减。

## 退回修改

1. 信息可以由原业务员修正时点击“退回修改”。
2. 退回原因必填，最长 200 个字符，应明确指出客户、仓库、商品、数量、价格或地址中的具体问题。
3. 系统将订单退回可编辑草稿，并保存最近退回原因。
4. 只有原创建业务员可以修改并重新提交；管理员不得另建重复订单代替修改。
5. 业务员重提后重新进行完整审核，不能沿用上次结论。

## 取消订单

1. 订单不应继续履约时点击“取消订单”，填写真实业务原因。
2. 已取消或已关闭订单不能重复取消。
3. 系统会检查关联拣货任务；任务已开始、已完成或存在执行数量时会阻止直接取消。
4. 取消成功后核对订单状态、任务状态、已分配数量和可用库存是否恢复。
5. 如果实物已经移动，先通知仓库隔离实物并按异常流程处理，不得绕过系统校验。

## 库存与履约报表

- “实时库存”按本货主显示在库、可用、已分配等数量；判断新订单能力时使用可用数量。
- “入出库履约”按日期查看汇总和逐行明细，并可切换“实际/计划”口径：实际入库取 RECEIVE 库存过账、实际出库取已完成 DISPATCH 发运；计划口径按订单业务日期和需求数量统计。
- “销售报表”用于业务趋势和订单查询，不代替库存流水或账单依据。
- 发现已取消订单仍在执行、货主已审核却没有保留任务、已过账任务库存未变化时立即上报。

## 共享客户与代办转货核对

- 客户通用档案可供多个货主关联使用；本货主的客户编号、负责业务员及配送资料以本货主关联为准。关联被停用后不能继续新开单，遇到客户缺失交管理员维护，不通过复制客户或改旧归属字段绕过限制。
- 仓库代办选择新货主时，销售单归新货主，另有独立转货单记录原货主转出。转货价与客户销售价分别核对；不能把转货金额当作终端销售额或已收款。
- 取得转货查看权限并具备后台登录条件后，可在“代办货权转移单”查看涉及本货主的证据。原货主只能看转货证据，不能据此访问新货主的客户销售订单；新货主按本货主范围核对销售履约。
- “待转货”表示已预留，只有“已转货并出库”及对应过账流水才能确认完成。不另建入库或出库单重复记账；异常交仓库管理员核对原任务。

## 计费与账单核对

1. 进入“计费总览”，选择账期并确认货主范围，查看总额、收费构成、状态和每日趋势。
2. 在“当前账单”点击“查看账单详情”。账期尚未生成账单时，按钮不可用；保留账期信息交财务确认，不能把未出账当成没有费用。
3. 核对账单期间、状态、不含税金额、税额和价税合计，再按服务日期、费用类型和关键词筛选明细。
4. 区分页面顶部整张账单金额与“当前筛选结果”金额；局部筛选为空或小计变化不会改变账单总额。
5. 逐行核对服务日期、费用类型、数量、单价、金额和说明。货主端账单行用于展示核对，不提供老板端的收费记录下钻或后台规则编辑；需要进一步追溯时把账单号和费用行信息交财务。
6. 差异上报必须包含货主、仓库、账期、收费类型、金额、筛选条件和业务单号；不得直接要求修改账单总额。

本岗位核对仓储服务账单，不通过该页面办理 POS 客户还款、退款或交班。登录切换或临时网络失败后先刷新账期和账单，核对范围再继续。

## 月结确认清单

- [ ] 本月订单量和业务台账一致。
- [ ] 退回、撤回和取消订单没有继续履约。
- [ ] 货主已审核订单均有可追踪的仓库处理状态。
- [ ] 期末库存抽查与仓库记录一致。
- [ ] 收费类型、计费数量和单价符合合同。
- [ ] 账单期间、不含税金额、税额和总额正确。
- [ ] 所有差异均有问题记录、责任人和处理状态。
