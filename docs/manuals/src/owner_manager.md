## 角色职责与权限

货主管理员负责本货主订单的商业审核、退回、取消，以及库存、履约报表和财务数据核对。规范角色组为 `WMS::货主管理员`，必须配置一个活动货主范围。

默认能力包括货主订单管理、货主运营报表和货主财务查看；不能查看其他货主数据，不能代替仓库管理员确认发布，也不能执行仓库现场拣货、复核或过账。

本册“货主端管理员”对应系统角色“货主管理员”。这是本货主的业务审核岗位；开通账号、分配权限和维护跨货主资料由系统管理员负责。

## 常用入口与岗位交接

| 要办的事 | 货主端入口 | 本岗完成标志与交接人 |
|---|---|---|
| 审核客户销售订单 | 功能 → 订单审批 | 通过后交仓库管理员确认；退回后交原业务员修改 |
| 审核到货预报 | 功能 → 到货预报／入库申请 | 通过后等待仓库确认，再跟踪分批验收及上架 |
| 审核客户退货 | 功能 → 退货与异常 | 通过后交仓库确认接收及现场验收 |
| 查实际收发 | 功能 → 出入库记录 | 以库存入账明细核对，差异交仓库管理员 |
| 管理库存预警 | 功能 → 库存预警 | 按本货主阈值跟进缺货、临期与未动销商品 |
| 对账 | 功能 → 计费总览 | 保存账期及差异证据，交财务核实 |

每次交接写明订单号、仓库、商品、数量和单位、当前状态、下一步责任人。审核通过只是完成本岗控制点，应继续查询仓库接单和实际入账结果。

## 每日审核顺序

1. 登录货主业务端，在“功能 → 订单审批”查看待审核数量。
2. 优先处理交付时限临近、一件代发和库存紧张订单。
3. 审核前打开详情，不能只根据列表摘要批量判断。
4. 审核结束后查看已通过、已退回和已取消标签，确认处理结果。
5. 定期核对实时库存、出入库记录、销售报表和计费总览。

## 订单审核通过

1. 在“订单审批”打开待审核订单。
2. 核对货主、履约仓库、客户、平台单号、商品、包装换算、数量、成交价、总金额和收件信息。
3. 确认订单为已提交、未关闭且状态允许审核；草稿、已撤回、已退回或已取消订单不能审核。
4. 复查当前商品价格规则。系统会使用审核时的最新最低价和折扣限制再次校验，不能依赖业务员提交时的旧价格。
5. 确认业务真实、价格合规、地址完整且不存在明显重复后点击“审核通过”。
6. 审核通过会冻结/分配库存，并创建或刷新 `RESERVED` 拣货任务；这时任务尚未发布，仍需仓库管理员确认。
7. 返回列表确认状态为货主已通过，必要时通知仓库处理待确认订单。

库存允许欠货的后台审核路径仍必须留下完整订单和分配结果；不得把“审核成功”理解为库存已经扣减。

## 退回修改

1. 信息可以由原业务员修正时点击“退回修改”。
2. 退回原因必填，最长 200 个字符，应明确指出客户、仓库、商品、数量、价格或地址中的具体问题。
3. 系统将订单退回可编辑草稿，并保存最近退回原因。
4. 只有原创建业务员可以修改并重新提交；管理员不得另建重复订单代替修改。
5. 业务员重提后重新进行完整审核，不能沿用上次结论。

## 取消订单

1. 订单不应继续履约时点击“取消订单”，填写真实业务原因。
2. 已取消或已关闭订单不能重复取消。
3. 系统会检查关联拣货任务；任务已开始、已完成或存在执行数量时会阻止直接取消。
4. 取消成功后核对订单状态、任务状态、已分配数量和可用库存是否恢复。
5. 如果实物已经移动，先通知仓库隔离实物并按异常流程处理，不得绕过系统校验。

## 到货预报审核与入库结果核对

1. 进入“到货预报／入库申请”，按状态或申请单号打开待货主审核记录。
2. 核对供应商、授权仓库、业务日期、预计到货时间、联系人、电话、商品、基本单位计划数量及采购单价。
3. 符合业务约定时点击“审核通过”，交仓库管理员“确认并发布”；资料有误时“退回修改”并写明原因，由业务员修正重提。
4. 后续在原申请查看逐行良品、破损、拒收、待到货、超收、已入账和已上架数量，以及各批照片、原因和处理记录。
5. 到货处理量为良品＋破损＋拒收；接收入库量为良品＋破损。拒收不增加库存，破损不增加可用库存。
6. 全拒收批次可显示“无需库存入账／无需上架”；不能把没有上架任务直接判断为漏入库。短收、超收和结束未到余量由仓库按实物处理并保留原因。

货主审核不等于验收数量已入账；验收批次待审核、入账失败或上架未结束时，把原申请号和批次号交仓库管理员跟进。

## 客户退货审核与跟踪

1. 在“退货与异常”打开申请，核对原销售订单、原商品行、退入仓库、可退数量、申请原因和照片。
2. 待货主审核时按真实业务“审核通过”或“退回修改”；通过后仍需仓库“确认接收”，不能直接认定实物已回仓。
3. 如需本岗发起退货，从原订单详情“申请退货”进入，填写数量和原因，保存草稿、上传证据后提交；是否可办以当前单据按钮为准。
4. 跟踪分批验收中的合格、残次、拒收、待到货及入账结果；有争议时追加说明并保留原单记录。
5. 此处是客户销售退货入库，不是 PDA 向货主或供应商“退货出库”，也不会自动完成客户退款、货款核销或仓储账单调整。

## 库存、出入库记录与预警

- “实时库存”按本货主显示在库、可用、已分配等数量；判断新订单能力时使用可用数量。
- “出入库记录”默认显示全部历史的入库、出库数量与次数。点击“按月”“按周”“按天”查看分段统计；周按周一至周日计算。可以自选开始、结束日期，并在该时间段内继续按月、周、天统计，点击“全部历史”清除日期限制。
- 点击入库或出库合计查看每次收发；也可按商品、按单据查看，继续进入分次明细和原始单据。商品详情的“收发历史”会带入商品条件；当前库存为零也可以从“出入库记录”查询历史。返回上层保留筛选和位置，点击“刷新”获取最新数据。
- 数量以实际库存入账为准：正常入库包含已入账良品与破损，拒收不计入；正常出库按实际扣库统计，包括 POS 和代办出库，不要求存在发运任务。销售退货、退供、撤销回补、盘点调整及货权转移分别列出，内部移库不增加正常收发数量。
- 所有日期按北京时间的实际入账时间计算。“历史累计／期间合计”与商品行的“当前现有／当前可用”含义不同；不同单位分别汇总，不能直接相加。收发序号按完整历史计算，筛选或翻页不会重编号。旧记录缺少来源、时间、次数或验收分类时显示“待核对／未记录”。
- 支持仓库、商品、单号、业务类型、批次筛选及最新／最早排序。有导出权限时，可按已查询条件导出商品汇总、单据汇总或逐次明细；编辑筛选后先点击“查询”，再导出。验收凭据可查看已记录的良品、破损、拒收和照片。
- “销售报表”用于业务趋势和订单查询，不代替库存流水或账单依据。
- 发现已取消订单仍在执行、货主已审核却没有保留任务、已过账任务库存未变化时立即上报。

例如某批实际验收良品 8 件、破损 1 件、拒收 1 件，到货处理量为 10 件，入账成功后的正常入库量为 9 件；不能把拒收的 1 件计入库存。出库记录按实际扣库统计，与业务员“入出库履约”的计划／发运口径应分别核对。

“库存预警”可查看低库存、临期／已过期和长期未动销商品。“阈值设置”按实际权限维护货主默认值或商品覆盖值，保存后刷新核对；业务员只读查看。各类商品可重复计数，“待核对”表示资料不足，缺失效期不能推算成未过期，长期未动销也不等于每批库存的库龄。

## 共享客户与代办转货核对

- 客户通用档案可供多个货主关联使用；本货主的客户编号、负责业务员及配送资料以本货主关联为准。关联被停用后不能继续新开单，遇到客户缺失交管理员维护，不通过复制客户或改旧归属字段绕过限制。
- 仓库代办选择新货主时，销售单归新货主，另有独立转货单记录原货主转出。转货价与客户销售价分别核对；不能把转货金额当作终端销售额或已收款。
- 取得转货查看权限并具备后台登录条件后，可在“代办货权转移单”查看涉及本货主的证据。原货主只能看转货证据，不能据此访问新货主的客户销售订单；新货主按本货主范围核对销售履约。
- “待转货”表示已预留，只有“已转货并出库”及对应过账流水才能确认完成。不另建入库或出库单重复记账；异常交仓库管理员核对原任务。
- 接收的转货商品受来源保护，名称、规格、品牌型号、基本单位、追踪规则及已有包装换算不能自行改成另一种商品。接收方经营价格可独立维护；资料或计量有误时把双方商品和原单交系统管理员核对，不能新建同条码商品绕过保护。

## 计费与账单核对

1. 进入“计费总览”，选择账期并确认货主范围，查看总额、收费构成、状态和每日趋势。
2. 在“当前账单”点击“查看账单详情”。账期尚未生成账单时，按钮不可用；保留账期信息交财务确认，不能把未出账当成没有费用。
3. 核对账单期间、状态、不含税金额、税额和价税合计，再按服务日期、费用类型和关键词筛选明细。
4. 区分页面顶部整张账单金额与“当前筛选结果”金额；局部筛选为空或小计变化不会改变账单总额。
5. 逐行核对服务日期、费用类型、数量、单价、金额和说明。货主端账单行用于展示核对，不提供老板端的收费记录下钻或后台规则编辑；需要进一步追溯时把账单号和费用行信息交财务。
6. 差异上报必须包含货主、仓库、账期、收费类型、金额、筛选条件和业务单号；不得直接要求修改账单总额。

本岗位核对仓储服务账单，不通过该页面办理 POS 客户还款、退款或交班。登录切换或临时网络失败后先刷新账期和账单，核对范围再继续。

## 月结确认清单

- [ ] 本月订单量和业务台账一致。
- [ ] 退回、撤回和取消订单没有继续履约。
- [ ] 货主已审核订单均有可追踪的仓库处理状态。
- [ ] 入库申请、客户退货均已核对分批验收、入账和后续处理。
- [ ] 库存预警及待核对商品已指定跟进人，历史收发与当前库存未混用。
- [ ] 期末库存抽查与仓库记录一致。
- [ ] 收费类型、计费数量和单价符合合同。
- [ ] 账单期间、不含税金额、税额和总额正确。
- [ ] 所有差异均有问题记录、责任人和处理状态。
