# Android PDA 扫码生命周期验收

在与生产一致的自定义基座和至少两台 PDA 上执行。验收时同时观察设备日志与后端请求日志。

1. 打开商品搜索页，扫描同一条码一次：只振动一次、只发起一次商品查询。
2. 从商品搜索页通过 `navigateTo` 进入入库购物车后再次扫描：隐藏的商品页不得产生查询。
3. 进入 POS，加入一个商品后切换到拣货详情页并扫描：只产生一笔拣货扫码请求，POS 购物车不得变化。
4. 返回 POS 后再次扫描：POS 应恢复接收，且只加入一次商品。
5. 在上述页面之间连续往返 20 次，每次各扫描一次：不得出现重复震动、重复业务请求或接收器注册/注销异常。
6. 人为模拟一次原生注销异常后重新显示页面：扫码能力应在下一次 `onShow` 恢复。

全部项目通过后再进入内部灰度；灰度期间按设备和操作员检查单次扫码对应的业务请求数量，并关注 POS 打印失败与重打日志。
