# 权限、数据隔离与终端会话

抽查当前工作区。覆盖服务端授权逻辑、两个移动端中的传统 PDA 请求入口、商城买家、报表导出和私有附件。本轮本地读代码、检查本机依赖并运行既有防御回归。没有使用真实凭据或向业务环境发送请求。

| 保护对象 | 观察到的控制，或应改进的地方 |
|---|---|
| 仓库、货主、买家 | 显式角色决定数据范围，停用账号、范围冲突及缺少相应过滤字段会被拒绝或返回空结果。仓库老板可配置多仓。生产配置禁止旧账号归属回退。商城列表、详情和同批次查询按当前账号的有效买家、客户、货主绑定取数。[范围](/wms/allapp/accounts/access.py:56) · [配置](/wms/wmsmaster/settings.py:510) · [买家筛选](/wms/allapp/salesapp/salemini_api.py:3767) |
| 报表、打印、照片 | 运营报表导出叠加独立权限并限制条数。老板导出另需经营角色。打印票据只对指定文档路径短时有效，并检查当前用户和密码状态。到货照片由可见订单沿同仓、同货主收货批次定位。退货照片从可见退货单定位。私有图片根目录与公开媒体目录分开。[运营导出](/wms/allapp/reports/views_operations.py:207) · [老板导出](/wms/allapp/reports/views_boss_p1.py:301) · [打印](/wms/allapp/core/print_tickets.py:25) · [到货照片](/wms/allapp/inbound/arrival_api.py:646) · [退货照片](/wms/allapp/inbound/customer_return_api.py:481) |
| 传统 PDA 网络与凭据 | 请求层固定选用局域网 HTTP 开发地址。登录、续期、业务请求和导出均依赖这个地址。安装在目标仓后可能无法登录，能到达地址时，链路上没有 TLS 提供的保密性。服务端生产配置另有可选的限定来源 Android HTTP 兼容例外，默认关闭。是否在某仓部署、是否已有凭据泄露均无证据。移动端以仓库约定的 HTTPS 地址构建，用两个隔离环境验证登录、刷新和导出均命中正确站点，发布环节拒收硬编码开发地址。[PDA 地址](/wms/wmspda/utils/request.js:15) · [请求](/wms/wmspda/utils/request.js:311) · [登录](/wms/wmspda/utils/request.js:824) · [服务端兼容范围](/wms/wmsmaster/security.py:39) |
| 共用设备换班 | 普通登出注销刷新令牌，已签发访问令牌可用至过期。普通访问期限 15 分钟，PDA 专用访问期限 24 小时。终端清除本地会话能减少留用机会，服务端没有随该次登出撤销这一设备的既发访问令牌。优先确认共用终端策略。若要求换班立即撤权，设计按设备会话撤销，验收原设备的旧会话无法继续操作，其他授权设备可以继续，停用和改密仍有效。[登出](/wms/wmsmaster/views.py:190) · [PDA 期限](/wms/wmsmaster/auth_views.py:24) · [通用策略](/wms/wmsmaster/settings.py:196) |

对 HTTPS 来源、原生 API 兼容范围、文件上传预算、微信回调签名和响应完整性等既有控制运行了定向无库测试，使用本机合成签名、图片或工作簿。商户实盘、反向代理、生产会话和全量接口授权没有本轮现场证据。[测试记录](/wms/var/assessments/2026-11-18/current-worktree/boundary-unit.xml)

**工具状态。** Codex Security 托管工作台在登记整库时未能读取正在生成的 PDA 构建目录。以 Django 目录重试，登记在 300 秒后超时。此次安全结论来自本地代码检查和明确列出的回归。没有完成托管整仓安全扫描，也没有核验当前线上依赖通报或实际部署配置。
